The targets here are a generic starting list. The DNS observer learns which services this house actually resolves, so you can measure those instead. It is off until you start it, and it changes nothing until the router points at it.

On the Pi: smoking-pi dns enable, then set the router's DNS server to the Pi and check the path with smoking-pi dns test. After a few days, smoking-pi dns adopt adds the services it found as targets. Already ran dns enable? Then it has not reported yet: smoking-pi dns status says why.
